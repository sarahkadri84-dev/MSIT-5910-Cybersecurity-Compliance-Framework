# Cybersecurity Compliance Monitoring Framework Using Rippling IT

MSIT 5910 capstone repository for requirements, design, controlled test scenarios, and evaluation artifacts. The project uses Rippling IT as the central implementation environment and SentinelOne for endpoint-protection verification where available.

## Scope
- 10-12 identity, access, device, and compliance controls
- NIST CSF 2.0 mapping
- Controlled/synthetic test scenarios
- Baseline versus post-framework evaluation
- No penetration testing or production exploitation

## Folders
- `src/`: lightweight compliance evaluation logic
- `tests/`: synthetic scenarios
- `docs/`: requirements and technical documentation
- `design/`: architecture/design artifacts
- `evidence/`: redacted or synthetic evidence only
