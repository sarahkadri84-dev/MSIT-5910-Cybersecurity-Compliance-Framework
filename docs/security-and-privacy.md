# Security and Privacy

The public portfolio is designed to demonstrate technical capability without exposing organizational secrets.

## Safeguards

- Synthetic test data only
- No production employee records
- No credentials, API keys, access tokens, or secrets
- No live security-policy modifications
- No penetration testing or exploitation
- Least-privilege assumptions for future integrations
- Data minimization for future evidence collection
- Redacted or synthetic evidence only

## Ethical Considerations

The design recognizes that workforce-security monitoring can affect employee privacy. A production implementation should use clear governance, purpose limitation, least-privilege access, retention controls, audit logging, and appropriate organizational notice and authorization.
